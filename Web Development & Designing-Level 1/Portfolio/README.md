# Personal Developer Portfolio — Smaran Bhoopalam

A personal developer portfolio built as part of the **OASIS Infobyte Web Development & Designing Internship — Level 2, Task 2: Personal Portfolio**. It uses a dark, technical, and minimalist aesthetic to showcase skills, interests, and selected projects in software engineering, embedded systems, and AI.

## Features

- **Single-Page Layout**: Smooth scrolling to dedicated sections — Home, About, Skills, Projects, and Contact.
- **Responsive Design**: Adapts fluidly to desktop, tablet, and mobile screens using CSS Flexbox and Grid with media queries.
- **Project Index**: Highlights key selected projects with technology tags and accurate availability status.
- **Dark Aesthetic**: Custom color palette (`#0B0F14` background, `#75E6A5` accent) designed for high contrast and readability.
- **Modern Typography**: Uses Inter for body text and JetBrains Mono for code-related elements (loaded from Google Fonts).
- **Mobile Navigation**: Hamburger menu with open/close toggle; closes automatically when a nav link is clicked or the user clicks outside.
- **Keyboard Accessibility**: All interactive elements have visible `:focus-visible` outlines.
- **No External Dependencies**: No JavaScript libraries or CSS frameworks — pure HTML5, CSS3, and vanilla JS.

## How to Run Locally

1. Clone or download the repository:
   ```bash
   git clone https://github.com/smaranbhoopalam/OIBSIP.git
   ```

2. Navigate to the portfolio folder:
   ```
   Web Development & Designing-Level 2/Portfolio/
   ```

3. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).

   > **Recommended:** Use the **Live Server** extension in VS Code for automatic reload on save.
